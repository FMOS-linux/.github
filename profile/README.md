# fmos

A console OS that boots into its own shell and runs console titles natively through
[AnyPS5](https://github.com/boykopovar/AnyPS5).

- **[fmos](https://github.com/FMOS-linux/fmos)** — the project: the image, the shell, the tooling.
  Milestones M0–M3 are met: the image boots into the shell, and a launched title reaches a real
  Vulkan device inside the guest. M4 — hardware matrix, installer, updates, recovery — is next.
- Everything else in this organization is **archived**. Those repositories belonged to an earlier
  plan for an Arch/Hyprland desktop distro that shared the FMOS name, and that plan was dropped.
  Their history is kept rather than deleted.
